# LifeDrop – Blood Donor Readiness Tracker

Windows Forms (C#, .NET 10) app using PostgreSQL and the MVC pattern.

## Setup
1. Install PostgreSQL and create a database named `blood_donor_registry`.
2. Run `database/schema.sql` in that database.
3. Copy `appsettings.sample.json` to `appsettings.json` and enter your PostgreSQL password.
4. Open the solution in Visual Studio and press F5.
